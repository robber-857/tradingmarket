# 免费公开预测接入

2026-11-10。页面：`http://127.0.0.1:5173/#calendar`。

## 来源与口径

- Scotiabank Global Week Ahead 公开周报：从索引发现最近六份报告，解析 PDF 的美国指标表，按 `BNS / Consensus / Latest` 列标题验证。BNS 单列为机构预测；Consensus 标为“Scotiabank 周报转引市场调查（表注：Bloomberg）”。不把 Latest 当预测，不把其他国家、CPI 指数水平、名义支出或私人就业当作目标指标。源表没有样本数或统计方法，系统不推断均值/中位数和机构名单。
- Cleveland Fed Inflation Nowcasting：解析公开 HTML 表格中的月环比和同比。CPI、核心 CPI、PCE、核心 PCE 单列为模型预测，季度年化率不混入月度指标。
- 不调用 Trading Economics、付费搜索或 LLM 进行此项采集；已有 AI 解读按钮仍独立按需调用。
- 来源公开可读不等于获得整份报告再分发许可。当前只保存本地提取结果、原文链接和来源日期，不提供原报告镜像或对外数据分发 API 的授权承诺。

## 匹配与显示

以指标（含核心/总量、同比/环比）和统计年月精确匹配。非农源表千人转为人。机构、模型不回填一致预期。原文只有日期时直接显示日期，不伪造更新时间；页面分别显示来源日期、收录时间、来源检查时间。

历史公开周报可以回补，标明“公布后收录，非当时系统快照”。只采用来源日期严格早于事件发布日的预测；同日只有日期而没有时刻的记录保守排除。匹配不到的当前期留空，不能借用上期。相同来源保留最新有效预测，原始记录保留约 400 天。相同事实再次抓取不覆盖首次收录时间。

源读取/格式校验失败保留旧数据，显示失败；旧记录只供参考，不填主预期栏。来源检查超过两天或未来事件预测超过十四天也视作旧数据。实际值可能是已修订序列，因此与历史预期的差不声称为首发意外程度。

## 每日调度

- 默认每天 **08:00 Australia/Sydney**（自动处理夏令时）检查一次。
- 后端 lifespan 启动独立协程，每分钟检查是否到期；没有打开网页也能采集。
- 停机后下次启动补查最近一个调度日，不重放所有错过日期。08:00 前启动时，若上个调度日未检查，会先补查。
- 本地文件 `server/cache/public-forecasts.json` 保存调度日、来源状态和预测；原子写入。进程内锁防止重复并发。请使用单 worker 后端；不支持多个独立后端同时写同一缓存文件。
- 每日尝试开始前即持久化标记，失败或中断不无限重试；下一日再检查。来源失败不会伪装成更新成功。
- 环境变量 `PUBLIC_FORECAST_BACKGROUND_ENABLED=0` 可关闭后台调度，默认开启。
- 当前为本机后端调度，不是云端常驻任务；关机期间不运行。没有新增付费账号。
