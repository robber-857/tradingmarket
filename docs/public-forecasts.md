# 免费公开预测接入

2026-11-10。页面：`http://127.0.0.1:5173/#calendar`。

## 来源与口径

- Scotiabank Global Week Ahead 公开周报：从索引发现最近六份报告，解析 PDF 的美国指标表，按 `BNS / Consensus / Latest` 列标题验证。BNS 单列为机构预测；Consensus 标为“Scotiabank 周报转引市场调查（表注：Bloomberg）”。不把 Latest 当预测，不把其他国家、CPI 指数水平、名义支出或私人就业当作目标指标。源表没有样本数或统计方法，系统不推断均值/中位数和机构名单。
- RBC Economics 美国周前瞻：从公开分类页发现最近六篇文章，只提取明确写出本行预测、指标、统计月份和同比/环比口径的句式；保留文章发布日期和最后修改时刻。支持 CPI 共用总量/核心预测、明确的非农人数和 PCE 前瞻，不能识别的文字留空。
- U.S. Bank Weekly Economic Outlook：读取当前公开周报中明确的本行预测；当前已核验 CPI 与核心 CPI 环比。没有把周报中转引的调查或图像表格当成本行预测。
- Cleveland Fed Inflation Nowcasting：解析公开 HTML 表格中的月环比和同比。CPI、核心 CPI、PCE、核心 PCE 单列为模型预测，季度年化率不混入月度指标。
- 不调用 Trading Economics、付费搜索或 LLM 进行此项采集；已有 AI 解读按钮仍独立按需调用。
- 来源公开可读不等于获得整份报告再分发许可。当前只保存本地提取结果、原文链接和来源日期，不提供原报告镜像或对外数据分发 API 的授权承诺。

## 匹配与显示

以指标（含核心/总量、同比/环比）和统计年月精确匹配。非农源表千人转为人。机构、模型不回填一致预期。原文只有日期时直接显示日期，不伪造更新时间；页面分别显示来源日期、收录时间、来源检查时间。

历史公开周报可以回补，标明“公布后收录，非当时系统快照”。只采用来源日期严格早于事件发布日的预测；同日只有日期而没有时刻的记录保守排除；银行文章提供精确修改时刻时，按该时刻与事件发布时间比较，不能用初始发布日期掩盖发布后的修改。匹配不到的当前期留空，不能借用上期。相同来源保留最新有效预测，原始记录保留约 400 天。相同事实再次抓取不覆盖首次收录时间。

源读取/格式校验失败保留旧数据，显示失败；旧记录只供参考，不填主预期栏。来源检查超过两天或未来事件预测超过十四天也视作旧数据。实际值可能是已修订序列，因此与历史预期的差不声称为首发意外程度。

## 每日调度

- 默认每天 **08:00 Australia/Sydney**（自动处理夏令时）检查一次。
- 后端 lifespan 启动独立协程，每分钟检查是否到期；没有打开网页也能采集。
- 停机后下次启动补查最近一个调度日，不重放所有错过日期。08:00 前启动时，若上个调度日未检查，会先补查。
- 本地文件 `server/cache/public-forecasts.json` 保存调度日、来源状态和预测；原子写入。进程内锁防止重复并发。请使用单 worker 后端；不支持多个独立后端同时写同一缓存文件。
- 每日尝试开始前即持久化标记，失败或中断不无限重试；下一日再检查。来源失败不会伪装成更新成功。
- 环境变量 `PUBLIC_FORECAST_BACKGROUND_ENABLED=0` 可关闭后台调度，默认开启。
- 当前为本机后端调度，不是云端常驻任务；关机期间不运行。没有新增付费账号。

## 多机构比较（2026-11-10）

机构区按预测值排序，显示与当前选定调查预期的差；缺调查时差值留空。仅对同指标、同统计期、同单位、状态正常的机构记录计算已收录家数、范围、中位数和最高最低差。模型、调查及旧记录不纳入机构汇总。同一银行多篇文章不重复计数；页面说明这是有限样本，不是全市场共识，并显示来源日期跨度。

新增银行无需额外 API Key 或付费搜索，随原有每日调度更新。新启用的来源即使当天已检查过其他源，也会单独初始化一次。

此次真实新增 RBC 七条、U.S. Bank 两条记录。十月 CPI 和核心 CPI 环比有三家机构可比；十月非农、九月 PCE/核心 PCE 环比有两家可比。并不保证每家每期都公开所有指标，未来周报的文字句式变化可能造成留空。

验证：268 项后端测试通过，前端构建通过；新增测试覆盖文章时刻、明确预测句式、缺失口径、歧义拒绝、千人换算、同银行去重、模型/调查/旧数据排除及新来源只初始化一次。真实浏览器核验 CPI 三家比较，390px 手机宽度无页面横向溢出。

### 机构分歧解读与七天入口

宏观 AI 使用冻结事件快照，计算同指标、同所属期、同单位的非过期机构样本上下沿、中位数、极差和实际值与各家预测差额。模型和调查不计入机构样本。聚合证据保留各家来源与更新时间；实际值可能修订、事后收录不能视为当时系统已知。数据事实与市场推论分开标记，未公布的影响为条件情景。机构样本不代表全市场共识。

页面数值栏改称“公开预期参考”，仍只使用已取得的调查值，机构和模型另列。首页七天卡片打开 `#calendar?range=7d`，可刷新保留筛选；以进入页面时刻为起点，按同类同发布时间计场次，保留各指标行。排除暂定时间；仅有日期的事件按美东日历日期纳入。完整日历按钮解除筛选。

### 机构原文观点（合并入口）

“多方观点”独立导航及演示内容已移除，旧 `#opinions` 书签转到宏观日历。事件详情“机构观点与分歧”保留数值对比，并展示 RBC / U.S. Bank 明确预测文段的英文短摘录（最多 25 词）、原文链接、发布/更新时间和原文收录时间。仅表格数据的来源显示“仅数值预测”，不补写机构判断。摘录可能截断，完整理由与限定条件以原文为准。

摘录随免费来源的每日更新收录，不调用 AI；旧解析版本只补查一次银行来源。段落变化形成新的证据版本，即使预测值相同也保留快照边界。AI 账本将原文标记为 source_opinion，与数据事实及 AI 推论分开；没有原文不能编造机构理由。当前只支持明确匹配指标和所属期的预测文段，不泛化采集整篇文章或事后评论。

### 原文中文翻译

机构观点卡片默认中文，可切换英文。首次查看时由现有 OpenAI 配置翻译已冻结快照中的短摘录；只接收 snapshot_id / record_id，不接受任意文本或 URL。译文标为 AI 翻译并显示翻译时间，与市场解读分开。按翻译版本与原文摘要缓存，相同段落跨指标复用；变更原文生成新缓存，失败不保存。数字、符号和百分号保持一致（允许英文月份转为中文月份），截断原文不补全。译文不加入宏观 AI 的原文证据账本。原文采集仍免费，首次 AI 翻译使用已配置 API 的额度。
