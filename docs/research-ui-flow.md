# 研究页面 UI 与跳转逻辑

全平台流程与 Homepage 规格见 [总 PRD](master-prd.md)。

## 设计原则

沿用现有 Lightness / Darkness 主题、侧栏与研究区结构。主导航保留「财报分析」「基本面分析」两个入口，不把所有指标拆成独立页面。每个页面先让用户定位公司和报告期，再读结论，最后展开计算与方法。

主操作是研究与追问；动效用于页面切换、章节定位和引用弹层，遵循 reduced-motion。财务数据与 AI 内容分区，避免把规则摘要和 AI 推论混为一谈。

## 财报分析

```text
股票搜索 / 公司快捷选择
  ↓
公司名 + 申报日 + 报告期选择 + SEC 原文
  ↓
三个重点：增长 / 现金 / 代价
  ↓
关键指标 → 点击数字 → 来源与公式弹层
  ↓
AI 解读与追问 → 点击引用 → 来源与公式弹层
  ↓
季度趋势 + 利润与增长 / 现金流 / 资产负债 / 方法
  ↓
导出证据快照
```

AI 生成由用户点击触发，未配置时显示配置说明；失败时保留已成功的对话并提供明确错误。回答按「核心判断、证据、继续验证」显示。后续问题可以编辑后发送。

## 基本面分析

公司和报告期下方有固定章节导航：**经营质量 → 行情与 Beta → 相对估值 → DCF 情景 → AI 解读 → 指标解释**。

| 章节     | 页面内容                                                           | 关键跳转                           |
| -------- | ------------------------------------------------------------------ | ---------------------------------- |
| 经营质量 | TTM 营收、营业利润率、简化 ROIC、ROIC−WACC                         | 数据值打开来源弹层                 |
| 相对估值 | 自动报价、P/E、P/B、P/S、适用限制                              | 「解读此指标」滚动到 AI 并预填问题 |
| DCF 情景 | 增长/利润率/WACC/g；再投资/税率；EV→股权桥；情景、敏感性、计算账本 | 打开 WACC；查看报价返回相对估值    |
| AI 解读  | 对当前已算出的结果解读、追问、引用和导出                           | 引用打开证据弹层，参数变化重置会话 |
| 指标解释 | 十一项指标的公式、用途和限制                                       | 选择指标 →「用当前公司追问 AI」    |

章节按钮在页内滚动，不修改已有一级页面 hash，不卸载计算面板，因此页内导航保留输入。进入「指标解释」时自动展开折叠区。手机上章节按钮换行，表格在自己的容器内滚动，页面不横向溢出。

## 资本成本操作链

```text
DCF 的 WACC 怎么算
  → 展开 CAPM/WACC
  → 自动带入历史 Beta 和股权市值估算；填写并核实 Rf、ERP、Kd、债务市值
  → Beta 也可手动覆盖，或打开独立历史价格工具
      → 粘贴配对复权价格 CSV
      → 计算 Beta、R²、样本量与窗口
      → 明确点击「应用 Beta 到 CAPM」
  → 计算 WACC
  → 明确点击「应用到估值」
  → DCF 重算，新的 AI 解读使用相同参数
```

Beta 不直接改动 DCF，WACC 也不在未确认应用时改动结果。修改已使用的 WACC 或税率会取消之前 CAPM 来源绑定；重新应用可恢复完整资本成本证据。用户导入价格标为未独立验证来源，不能显示为官方行情。

## 上下文规则

- 侧栏切换财报/基本面保留当前股票；同一浏览器会话按股票记住所选报告期。
- 更换公司按该公司的已记报告期或最新可得报告展示，不把另一公司的日期强行套用。
- 估值参数仅在当前基本面页面保留，离开后再次进入重新以默认假设开始；当前不做跨会话保存。
- 公司、报告期、快照、估值参数变化时清除旧 AI 会话；新问题始终绑定页面当前证据。过期响应不会写回新页面。
- 基本面计算尚未完成或参数无效时，AI 生成按钮不可用；不会拿旧估值解释新输入。
- 从指标解释跳转只预填问题，不自动调用，用户可编辑后发送。

## 状态设计

| 状态                  | 页面行为                                 |
| --------------------- | ---------------------------------------- |
| 缺少 Key              | 展示 .env 配置位置与检查配置按钮         |
| 已配置                | 展示模型名；不等同于已验证额度和权限     |
| 正在生成              | 明确加载状态，防止重复提交               |
| 引用校验失败          | 不展示该答案，允许手动重试               |
| OpenAI 额度/权限/超时 | 返回具体可操作说明，不暴露供应商原始错误 |
| 无效 P/E / P/B        | 显示不可得及原因，不展示负倍数充当便宜   |
| 会话失效              | 明确提示并提供「开始新解读」             |
| 数据更新失败          | 保留来源时间和缓存标识，不伪装实时       |

当前未加入全屏聊天侧栏，避免同时占用财务表格的阅读宽度。未来可在大屏增设固定研究侧栏，但仍复用同一上下文与引用机制。

## 行情章节

最新报告期自动加载报价、1M/6M/2Y 拆股复权曲线、SPY Beta、R² 和样本区间。曲线支持悬停及键盘滑块查价。「解读市场敏感度」预填 AI 问题；导出保留行情快照和源参数。更换公司、报告期或刷新行情会取消过期响应并重置 AI 上下文。历史报告期暂停当前行情联动；缺失 Key、权限、时点或复权口径时不填入模拟值。

## 动态证券入口

研究页搜索按 SEC 目录返回代码、发行人、CIK、交易所；支持直接输入代码回车、候选上下键选择、快捷入口和最近研究。切换股票清理旧报表、旧行情与 AI 会话，错误结果不残留上一家公司数字。全局搜索使用同一目录，新代码也可加入关注清单并跳转。

DCF 不适用或缺少必要输入时，仍能在基本面页面解读可得财报与行情；AI 标题注明当前无有效 DCF。申报格式完全不适用时显示具体原因，保留搜索入口供更换股票。
