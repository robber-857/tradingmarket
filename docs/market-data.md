# 真实行情、历史价格与自动倍数

基本面研究现已按 SEC 动态代码目录扩展上市公司。行情按已核验财报快照中的代码请求，并校验返回证券与币种；不保证所有目录证券均有供应商权限。数据链路为：Twelve Data 报价与日线 → Python 校验及数学计算 → 行情快照 → 估值和 OpenAI 解释。浏览器不持有数据源密钥。

## 配置与运行

在项目根目录 `.env` 设置 `TWELVE_DATA_API_KEY=`。从 [Twelve Data 控制台](https://twelvedata.com/account/api-keys) 获取密钥，保存后点击「刷新行情」，无需重启。首次启用代码需启动/重启 `npm run api`，前端为 `npm run dev -- --port 5173 --strictPort`。

当前不是逐笔流：进入最新报告期或手动刷新时请求数据；报价缓存 60 秒、历史日线 6 小时。后端合并同样的并发请求，共用 SPY 缓存；供应商请求间隔至少 8.1 秒，无自动重试。首次一家公司约需半分钟。权限失败、限流、字段异常分别提示，不回退到演示值。配置检查仅返回布尔值。

后端使用固定 `https://api.twelvedata.com` 地址，密钥放在 Authorization 请求头，不出现在 URL、响应、前端代码或导出文件中。

## 数据口径

- `/quote`：常规时段、USD、未经复权的报价；`last_quote_at` 是报价时间。`timestamp` 是 K 线开盘时点，不能用来假装最后成交时间。缺少时点、时点在未来、开市时超过二十分钟或超过五天的报价不用于计算。
- `/time_series`：`interval=1day, outputsize=600, adjust=splits`，分别取股票和 SPY；另取股票 `adjust=none` 供拆股股数核对。美国东部当天日线被排除，包含 DST 时区处理。
- 历史曲线展示拆股复权收盘价，不是分红再投资总回报。1M/6M 分别展示最多 21/126 根日线，2Y 按过去 730 天限制。
- 最新已披露股数取 SEC 正式报告。拆股修正因子 = 股数时点对应的原始历史收盘价 / 同日拆股复权价；非交易日向前最多七天。两套日线的末端必须一致，否则不计算倍数。该方法不追踪披露后的回购、增发，市值是估算。
- 只有当前财报快照的最新报告期启用行情联动。旧报告期保留独立 DCF 模型，避免拿现在的价格冒充历史时点估值。财报是最新可得修订口径，不是 point-in-time 回测库。

## 确定性公式

```text
估算市值 = 行情价格 × 拆股修正的最新已披露股数
P/E = 估算市值 / 最新报告期 TTM 净利润
P/B = 估算市值 / 最新期末母公司权益
P/S = 估算市值 / 最新报告期 TTM 营收
日简单收益率 = 当日收盘价 / 前日收盘价 − 1
Beta = Cov(股票收益率, SPY 收益率) / Var(SPY 收益率)
```

亏损、零利润、负权益或数据缺失不输出对应倍数。倍数使用已披露股数；DCF 的股数仍可作为情景参数调整，初始自动采用拆股修正股数，不能认为两者永远相同。

Beta 用最多两年拆股复权日价格收益率、带截距 OLS，并返回 R²、样本数与起止日期。沿 SPY 已返回的交易日序列对齐；某日股票缺失时舍弃此前样本，保留连续可配对后缀，不跨缺口计算收益。至少 61 个价格点；末端超过七天、基准方差不足时不计算。若供应商同时漏掉同一个交易日，当前没有独立交易日历可再核验，此为数据质量限制。Beta 不含分红再投资，不是未来风险预测。

自动 Beta 和估算股权市值带入 CAPM 面板。Rf、ERP、债务成本和债务市值仍需研究者核实；计算并明确点击应用 WACC 后才改变 DCF。超出当前 CAPM 允许的 Beta 0–5 时保留历史结果，不截断或自动套用。

## AI 与追溯

每次行情形成服务器 JSON 快照（`server/market_snapshots/`，不入版本库）。估值和 AI 请求仅传快照 ID，后端核对股票、财报快照与报告期，重新绑定对比价格。客户端伪造价格不能替换报价证据。导出包含源参数、采集时间、价格曲线、Beta 方法与倍数输入，接口错误不包含密钥。

AI 可引用 P_QUOTE、P_BETA、P_BETA_R2、V_PE/PB/PS。行情快照变更会改变会话指纹；历史答案保持当时快照而非悄悄换成新报价。DCF 估值、税率、增长等仍标为条件假设。数值与引用校验不等同于完全消除语言推理错误。

## 供应商范围

[官方美股数据说明](https://support.twelvedata.com/en/articles/9935903-us-equities-market-data)说明默认实时源来自部分交易场所，并非全市场合并实时数据；历史日线的覆盖和发布时间不同。面向外部客户分发需要匹配相应 US Equities Add-On，不能把本机 API 可用当作 SaaS 再分发授权已完成。
