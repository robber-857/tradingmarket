# 每日简报与期权研究

## 每日 AI 简报

入口 `/#daily`。默认每天 **08:00 Australia/Sydney**，仅在 FastAPI 后端运行时执行，自动处理夏令时。当日超过时点才启动服务，会补生成当天一份；不会用今天的数据补造以前日期的简报。可以提前点击“立即生成今日简报”，成功后当日自动任务不再重复调用。

后端配置（没有新增收费新闻 Key）：

```dotenv
DAILY_BRIEF_ENABLED=1
DAILY_BRIEF_HOUR=8
```

不配置时也使用上述默认值。配置按分钟读取，无需为了改生成时间重启。OpenAI 继续使用已有 `OPENAI_API_KEY` 和 `OPENAI_MODEL`，自动生成会产生模型使用费用。关闭电脑或停止后端后不会运行，没有新增操作系统任务、Codex 提醒或消息推送。

过程：公开 RSS → 最近二十四小时候选 → 按美股、Crypto、宏观选取最多六则材料 → AI 选择重点事件、传导、风险与待验证因素 → 引用和数字校验 → 持久化成功版本。主题标签可以重叠，不是六则材料之外的新增来源；模型只看到标题和有限摘要，未阅读全文。没有新鲜材料就保留失败状态，不生成虚构日报。

保存位置为 `server/cache/daily-briefs.sqlite3`。日期为唯一键，事务占位阻止重复生成，成功版本不可被当天重复请求覆盖。保留原始材料、生成时间、模型、提示版本和引用账本，历史阅读不依赖临时新闻快照。列表显示最近 365 个日期，数据库中的旧版本不自动删除。

失败自动重试间隔至少一小时、每日最多三次。若进程在请求中途退出，保留 generating 状态，由用户点击“重试中断任务”，避免无法确认结果时默默重复计费。接口：`GET /api/briefs`、`GET /api/briefs?day=YYYY-MM-DD`、`POST /api/briefs/generate`。

## 期权数据

入口 `/#options`。输入代码或英文公司名，候选名称来自现有 SEC 目录。选择公司后获取 Nasdaq 的公开延迟期权链；本机无需额外 Key。不保证所有股票都有可用期权，不支持 Crypto 期权，受来源字段、覆盖与访问状态限制。

来源：[Nasdaq 期权链](https://www.nasdaq.com/market-activity/stocks/aapl/option-chain)、[Nasdaq 财报日历](https://www.nasdaq.com/market-activity/earnings)。公共站点接口不是有 SLA 的商业数据合同，字段可能变化；对付费客户再分发前应确认供应商许可。没有接入 OPRA 实时逐笔或机构订单流，也没有绕过登录或反爬验证。

- 查询未来一年内、来源返回的全部价内外标准股票合约，显示可用到期日。默认选择至少七天后的最近一期；财报入口选择覆盖预计公告时点的最近一期。
- 期权链缓存十五分钟，财报日历缓存六小时；网络失败冷却五分钟，不把过期链当作当前数据。当前窗口可能不足一年，以实际返回的到期日为准。
- 报价保留 bid/ask/last，缺失值不当零；中间价仅在 `0 < bid <= ask` 时计算，不能视作保证可成交价。
- 来源标的价格日期保留在页面，超过四个自然日拒绝计算。来源没有逐合约报价时间，采集时间不是成交时间，不把延迟报价标为实时。
- 根据合约代码解析到期日及行权价并核对分组，排除不能确认标准交割的调整合约。到期模型时点为美东 16:00，未建模特殊交易日提前收市；临到期研究需核对实际交易所安排。
- OI 可能为前一交易日存量，成交量可能为日内累计；不能从这两个数推断主动买卖、机构身份或净多空。

## 数学与口径

所有计算由 Python 完成，AI 不决定数值。公式参考 [OIC 定价模型说明](https://www.optionseducation.org/advancedconcepts/black-scholes-formula)。

### BSM、IV 与 Greeks

`d1 = [ln(S/K) + (r-q+σ²/2)T] / (σ√T)`，`d2 = d1-σ√T`。

`C = S exp(-qT) N(d1) - K exp(-rT) N(d2)`。

`P = K exp(-rT) N(-d2) - S exp(-qT) N(-d1)`。

`T` 是计算时刻至到期时点的实际秒数 / (365×86400)。`r` 为连续复利无风险利率假设，默认 4%；`q` 为连续股息率假设，默认 0%；均不是自动获取的实时市场事实，可在页面调整。

IV 使用中间价反解，二分范围 0.01%—500%；超出模型价格界限返回缺失。相对买卖价差 `(ask-bid)/mid > 30%` 的合约不反推 IV 或 Greeks。

- Delta = `∂V/∂S`；Gamma = `∂²V/∂S²`。
- Theta 按每自然日显示；Vega、Rho 按波动率、利率变化一个百分点显示。
- Greeks 为每股口径。当前标准合约乘数假设为 100 股，非标准交割合约不适用。
- BSM 为欧式近似；美股期权通常具有提前行权特征，不能把欧式 IV 称作完整美式公允估值。
- ATM 同一 IV 下另算 160 步 CRR 美式价格：`u=exp(σ√Δt)`、`d=1/u`、`p=[exp((r-q)Δt)-d]/(u-d)`，每步取贴现续持价值与立即行权价值的较大者。此比较不重新校准美式 IV，未处理离散现金股息。

### 分布、跨式与异动

- Put/Call OI 比 = 可用 Put OI 合计 / 可用 Call OI 合计；成交量比同理。显示缺失 OI 数量，不能视为完整市场总体。
- 持仓峰值是当前返回样本中 OI 最大的行权价，不自动命名为支撑、阻力或价格目标。
- ATM 是与标的价格最近的行权价。跨式中间价 = 同到期同行权价 Call mid + Put mid；到期盈亏平衡 = `K ± 跨式成本`。另显示两腿 Ask 合计，说明中间价与买入成本差异。
- `S × IV × √T` 为模型波动尺度，不是保证概率区间，也不是独立提取出的财报单日波动。
- Max Pain 最小化 `Σ OI×100×到期内在价值`；只在 OI 无缺失时计算，保留并列最小点。它是静态样本清算量，不是方向预测。
- 异动筛选：成交量≥100、OI≥20、成交量/OI≥3、相对价差≤30%。是公开链筛选线索，不是基于历史分布的统计异常，不声称检测到大单扫单或机构建仓。

### 财报预期波动

日期可查询美东今天至未来十四天。默认按供应商市值列出前十二家公司作为关注入口，**不是期权热度排名**。财报时间来自 Nasdaq 预计日历，需核对公司公告。

盘前按 09:30、盘后按 20:00、未提供时刻按 23:59 美东作为保守边界判断覆盖。当天盘后财报不被当天 16:00 到期期权覆盖。若事件已过去、无覆盖到期或日期不可核实，页面明确提示，不输出伪造财报预测。跨式反映整个期限成本；尚未扣除普通交易日波动，也没有历史 IV、事件后实际价格或概率校准。

## 策略学习

更新：策略页已新增默认「真实合约与策略比较」，详见 [真实链策略比较](live-option-strategies.md)。下述教学输入仅适用于独立「教学策略模板」标签。

入口 `/#strategies`，共十一种：买 Call、买 Put、备兑 Call、保护 Put、牛市 Call 价差、熊市 Put 价差、牛市 Put 信用价差、熊市 Call 信用价差、买入跨式、铁鹰、领口。

初始输入为明确标注的教学假设，不使用虚构的“当前报价”。编辑行权价与权利金后由后端重新计算：

`Π(ST) = 股票股数×(ST-S0) + 100×Σ quantity×[intrinsic(ST,K)-premium]`。

最大盈亏由价格为零、全部行权价拐点、无穷远右尾斜率确定；不是从有限绘图区间找最大最小。盈亏平衡以分段线性求根，理论收益/损失无上限显示“无上限”。计算假设同一到期日，不含佣金、滑点、融资、股息、保证金和提前指派。自由编辑腿以后，应按实际腿结构理解，策略名只是起始模板名称。

来源：[OIC 策略知识库](https://www.optionseducation.org/strategies/all-strategies)、[跨式策略](https://www.optionseducation.org/strategies/all-strategies/long-straddle)。

## AI 与页面跳转

期权分析 → 选股票 → 选到期日/参数 → 分布、波动成本、异动 → AI 解读与追问。修改参数后旧 AI 暂不可用，重算后开始新会话；会话绑定计算快照，最长八轮、快照一小时有效。来源和计算数字通过账本引用，未经校验的输出不展示。

财报预期波动 → 选预计公告日 → 选公司 → 自动选择覆盖事件的到期日 → 查阅证据与风险。探索策略 → 十一种模板 → 修改腿 → 即时重算 → AI 解释教学假设。真实链与策略教学示例分开标注。

期权接口：`GET /api/options/earnings`、`POST /api/options/analyze`、`POST /api/options/strategy`、`POST /api/options/explain`。期权原始缓存与快照不入版本控制，持久化目录为 `server/cache/options/`、`server/option_snapshots/`。账号鉴权和商用部署仍需后续实现。
