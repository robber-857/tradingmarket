# 市场总览与自选行情

市场行情位于首页统计条下方。默认 Nasdaq 100、黄金、BTC、标普 500；可添加白银、美国十年期国债收益率、美元指数、VIX，支持移除全部及恢复默认。选择保存在当前浏览器 `meridian.dashboard.markets.v1`，不与股票研究关注列表混用。

## 展示与分页

- 桌面行情每页四项，手机两列；超出四项翻页。
- 研究重点每页两条，宏观清单每页两项，市场热点每页三条，研究关注资产每页六项。
- 新闻保留全部最近二十四小时的可用条目；切换主题回到第一页。
- 桌面上下两组采用相同列宽，分页保留阅读区域，避免内容数量直接拉长页面。

## 数据口径

`GET /api/market/overview` 从 Yahoo Finance 公开 chart 数据返回八个固定市场；服务端缓存五分钟，前端在页面可见时每五分钟读取一次。无需新增 API Key。公开接口可能延迟、限流或改变，不作为保证实时的数据服务。

- Nasdaq 100 为 `^NDX`，标普为 `^GSPC`，不是 ETF 代替。
- 黄金 `GC=F`、白银 `SI=F` 是期货参考报价，不是现货。
- BTC 为 `BTC-USD`；美元指数 `DX-Y.NYB`；VIX `^VIX`。
- 美债为 `^TNX` 十年期收益率，以百分比显示；变化为收益率差乘一百，单位基点，不显示成债券价格。
- 涨跌以报价交易所时区的前一有效交易日收盘计算；BTC 按 UTC 日线。不能使用 `chartPreviousClose` 代替前收盘，因为它对应请求区间起点。
- 走势图使用返回的近月日线；展示报价时间与可点击来源。缺失不补零，源站失败时仅使用明确标注的本地缓存；缓存写入失败不丢弃有效报价。
