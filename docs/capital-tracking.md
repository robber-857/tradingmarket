# 大资金动向

页面 `/#capital`，位于「市场情绪」下方。首批跟踪伯克希尔（巴菲特）、高盛、摩根大通、佩洛西、特朗普、贝森特。

## 数据口径

- 机构：SEC submissions 自动发现最新两个报告期，下载原始 13F 信息表 XML；核对行数、申报市值总额。2023-01-03 起金额按美元，较早文件按千美元。以 CUSIP、证券类别、Put/Call 和数量单位合并，期权不混入同名普通股。更正版 RESTATEMENT 替代原版，NEW HOLDINGS 追加；不支持的修订序列停止更新并保留旧数据。
- 相邻季度按数量比较。价格变化不算买入；新增 / 不再披露不直接称建仓 / 清仓。拆股、转托管、保密处理等也可能改变数量。机构申报可能含客户管理资产，不能解释为管理者个人或银行自营仓位。
- 佩洛西：众议院当年及前一年官方 ZIP 索引，按申报日找最新 PTR。含配偶，金额为区间。
- 特朗普：白宫公开披露目录自动发现定期交易报告，日期取报告标题，非网页上架日。
- 贝森特：Open Cabinet 公开目录发现 OGE PDF，数字提取自官方 PDF；目录日期来自第三方，覆盖不保证完整。
- 个人报告每份最多提取 40 条；年度资产选取公开证券 / ETF，交易按时间排列。记录附报告日期、交易日期、归属、原始页码、备注。只展示最新报告的部分明细，其他报告提供原文链接。没有从交易重建仓位、估算净资产或展示跟单回报。

## 更新与配置

- `GET /api/capital/profiles`：六个对象及缓存摘要；`GET /api/capital/{id}`：明细、来源、q/category/offset/limit 筛选与分页。
- 访问时检查 6 小时缓存；失败后 30 分钟重试，保留上次成功检查时间与记录，标记 stale。没有成功数据时明确显示不可用，不假造零持仓。
- `GET /api/cron/capital` 使用现有 CRON_SECRET 鉴权，有限并发更新全部对象。`deploy/capital-cron.sql` 可独立配置每 6 小时任务，不改其他任务。
- 复用 `SEC_USER_AGENT` 联系标识、`OPENAI_API_KEY` 与 `OPENAI_MODEL`。`CAPITAL_AI_EXTRACTION_ENABLED=0` 可关闭个人 PDF AI 提取；仍发现新报告并提供原文。默认开启；共享结果不扣用户研究额度，但有平台模型调用成本。
- 原始 PDF 仅在提取请求内存使用；按文件 SHA256 与提取版本缓存结构化结果，避免重复调用。文本型 PDF 加做名称 / 金额 / 日期与引用页校验；扫描件为 AI 识别，明确标注可能遗漏，不视为人工核验全量数据。
- 数据存于 `server/cache/capital/`，走现有 storage_path（本地文件 / 私有 S3）。跨实例租约与进程锁去重，白名单 URL 与重定向检查限制抓取来源，限制下载体积，不执行文档中的指令。
