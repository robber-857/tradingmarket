# 宏观日历：免费官方数据与 AI 解读

2026-11-09 实现。入口：`http://127.0.0.1:5173/#calendar`。

## 免费模式与配置

默认免费模式不需要新增 API Key。沿用已有 `OPENAI_API_KEY`；AI 只在用户点击生成或追问时调用，OpenAI 仍按实际用量收费。

可选增强：根目录 `.env` 的 `TRADING_ECONOMICS_API_KEY=client:secret`。用于有美国经济日历权限的账户；未配置不影响官方数据。密钥仅在后端读取，通过 Authorization 请求头发送，不进入前端、缓存内容或日志。保存后下一次日历请求生效。

**市场一致预期没有免费官方来源接入。** 页面保留预期栏，缺失显示“暂无预期 / —”；不以历史前值、自研预测、AI 推断或 TEForecast 填充。可选供应商接口已经实现，但当前未配置凭据，没有完成账户权限和实际响应的端到端验证。

## 数据来源与当前覆盖

| 指标 | 数值来源 | 日期来源 | 当前口径 |
| --- | --- | --- | --- |
| CPI / 核心 CPI | BLS Public Data API | BLS iCalendar；不可用时使用美国劳工部转载的 BLS 原始 PDF | 季调环比、未季调同比，当前修订版序列计算值 |
| 非农 | BLS `CES0000000001` | 同上，Employment Situation 新闻稿包含本期与下期准确时间 | 季调就业人数相邻月份之差，千人转为人 |
| PCE / 核心 PCE | BEA 最新 Personal Income and Outlays 新闻稿月度表 | BEA 排期与新闻稿 embargo 时间 | 月环比；不把名义消费支出增速当物价增速 |
| FOMC | 美联储已公布政策声明 | 美联储会议日历及已发布声明的 release time | 完整目标利率区间；前值取上次实际取得的声明 |

官方链接：

- [BLS API](https://www.bls.gov/developers/)，[BLS 日历](https://www.bls.gov/schedule/news_release/bls.ics)。
- [美国劳工部经济数据原文](https://www.dol.gov/newsroom/economicdata)。
- [BEA PCE 数据入口](https://www.bea.gov/data/personal-consumption-expenditures-price-index)，[BEA 排期](https://www.bea.gov/news/schedule)。
- [FOMC 日历与声明](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)。
- [Trading Economics 字段口径](https://docs.tradingeconomics.com/economic_calendar/schema/)。

本机 BLS 网站日历与 HTML 新闻稿返回 HTTP 403，但 BLS 公共 API 和美国劳工部原文可访问。系统显示直连覆盖提示，并通过劳工部原文补充当前和下一次排期；不会根据“每月第一个周五”等惯例生成更远期日期。

免费版本提供最新官方报告和当前可获取的排期，**不是完整历史发布数据库**。日期筛选只筛选已获取的事件；更早报告暂未回溯。PCE 本轮实现总量与核心的环比，尚未实现完整同比/分项历史表。没有日期证据的 BLS 最新序列单独展示，不能当作有明确发布时间的历史事件。

## 计算与修订

- CPI 环比 = `(本月季调指数 / 上月季调指数 - 1) × 100`，显示一位小数。
- CPI 同比 = `(本月未季调指数 / 去年同月未季调指数 - 1) × 100`。
- 核心 CPI 使用对应扣除食品和能源序列，环比和同比的季调口径独立。
- 非农月增量 = `(本月季调非农人数 - 上月季调非农人数) × 1000`。
- 缺少相邻月或去年同月时留空；不跨缺失月份求差，不把年度平均 M13 当作月份。
- BLS 序列计算的前值与实际值属于当前 API 修订版本，明确标记“不是首发值”。发布时间来自原始新闻稿，数值来源独立链接到序列。
- BEA 前值为本次新闻稿所列上月值，可能已修订；未获得修订前数值就不显示修订幅度。
- 待公布事件只在指标和相邻统计期都匹配时沿用最近实际值作为前值；不能把两个月前的数据当作上月前值。
- 若接入 TE：`Previous` 是修订后前值，`Revised` 是修订前的前值；`Forecast` 才是一致预期，`TEForecast` 不使用。
- 预期差 = 实际值 − 一致预期，仅在同一事件、相同单位且都可解析为标量时计算。百分数之差显示“百分点”，就业人数显示“人”；不将政策利率区间强行压成一个数。

## 时间、缓存与失败

使用带时区的 UTC 存储时刻，BLS/BEA 的美东时钟通过 IANA `America/New_York` 转换，自动处理夏令时。UI 可选美东、北京、悉尼。筛选窗口按美东日历日计算，默认过去 30 天至未来 60 天，最大跨度 120 天。

美联储会议日历只确认日期时显示“美东 · 时刻待确认”，不会把惯例下午两点当已核实发布时间，也不会因切换时区把只有日期的事件移到另一日。已公布声明出现明确 release time 后展示准确时刻。

供应商日期为 UTC；DateSpan 非确定值标“暂定”。未来事件即便错误返回 actual，也会隐藏该值。已过时间但 actual 缺失的事件显示“等待核验”，不是“已公布”。

页面可见时每分钟检查后端。实际源缓存：BLS 序列 / 官方排期 / 劳工部 PDF / Fed 声明一小时，BEA 最新新闻稿与入口、DOL 索引十五分钟，TE 一分钟。免费方案不承诺秒级发布时间更新，刷新按钮也不绕开数据源限流缓存。失败时仅允许近期缓存（普通源一天，排期与劳工部 PDF 七天），标记 stale 并显示抓取时间；更旧数据不作为可用缓存。密钥错误、额度不足和解析失败不会替换为演示值。

## AI 与会话

- `GET /api/macro/calendar?start=YYYY-MM-DD&end=YYYY-MM-DD` 返回事件、独立最新序列、覆盖提示与来源。
- `POST /api/macro/explain` 接受服务器事件 `snapshot_id`、可选 `question` 和 `conversation_id`，不接受客户端提供经济数字。
- 每个事件写入不可变快照。会话绑定该快照；切换事件/加载新数据后开启新解读。后台轮询不会悄悄更换正在追问的证据。
- 服务器保存会话历史，一小时过期，最多八轮，最多两项宏观 AI 并发，每分钟十次调用。
- 使用共享 OpenAI Responses 传输和结构化输出。宏观提示词及校验与财报独立，保留既有财报行为。
- 数值必须来自证据占位符，引用 ID 必须存在；服务器替换数字、链接来源。没有一致预期不能断言超预期；未公布只做条件推演。
- 美股与 BTC/ETH 影响是分析推论或条件情景，不能伪装成已发生的行情事实。当前没有联接事件窗口内跨资产价格、点阵图、官员发言或发布会，因此不能证明因果或生成确定涨跌结论。
- 所有上述校验约束数字与来源，不等于验证了每条经济推论。

## 页面路径

宏观与事件 → CPI / 非农 / PCE / FOMC 筛选 → 日期与公布状态 → 选中事件 → 前值、预期、实际和预期差 → 来源 / 口径 → AI 解读 → 追问。

桌面双栏展示列表和事件详情。手机将三项数值排列在每个事件名称下，避免宽表裁掉实际值；点选后滚动至详情。新闻已接真实 RSS，总览已汇总简报、新闻与官方事件；独立情绪和多方观点仍为演示。首页选择事件会进入此页的对应详情，参见 [总 PRD](master-prd.md)。
