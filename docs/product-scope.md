# 产品范围与真实数据版本实施说明

本文件保留实施背景；功能状态、Homepage 和后续优先级统一以 [总 PRD](master-prd.md) 为准（2026-11-10 更新）。

## 定位

为美股与加密资产个人研究者提供方向感：今天应该关注什么、为什么重要、不同观点分歧在哪里、哪些证据可以验证。第一阶段重心是宏观基本面与市场环境，而非自动下单或给出未经校准的涨跌概率。

当前已经实现体验层，以及基于 SEC 动态代码目录的官方财报获取、确定性财务指标和 FCFF 估值服务。详见 [深度研究 PRD](research-prd.md) 与 [计算方法](financial-methodology.md)。宏观日历已接入免费官方数据与 AI 解读，详见 [宏观数据](macro-data.md)。市场热点已接入公开 RSS、Reddit 指定社区榜、AI 来源解读与每日新闻目录，详见 [市场热点](market-news.md)。X 接口已适配但未配置验证；独立情绪页与多方观点仍为演示；总览已接真实简报、新闻、官方事件和参考行情；学院保留本地发布并加入服务端课程授权，会员与测试支付已有本地实现，真实渠道尚未验收；公开内测已部署，财报 S3 兼容修复待发布，见 [迁移复核](validation-2026-11-10-migration-audit.md)。

## 用户与运营流程

1. 个人用户通过邮箱一次性链接登录，首次登录创建免费账号；本机模式提供开发链接，生产 SMTP 尚未验收。
2. 管理员可按邮箱添加用户、分配限时会员、撤销手动授权；全部由服务端检查并记审计。
3. 测试支付与 webhook 已实现，服务端验证渠道付款后发放权益；真实沙盒交易与退款未完成，正式收款关闭。
4. 用户可保存财报 / 估值研究归档，手动保存 / 读取关注清单；自动同步冲突合并与完整策略恢复尚未完成。
5. 课程已有服务端会员权限，原学院 UI 与本地发布保留；正式内容编辑、审核和发布工作流待开发。

当前权限包括普通用户、账号管理员及独立的退款审核管理员。研究员 / 编辑角色属于后续内容运营规划；不能用按钮显隐替代服务端访问控制。不做 ToB、团队或白标功能。

## 数据流

外部授权数据源 → 采集任务 → 原始记录与出处 → 规范化、去重和实体识别 → 分析与人工复核 → 用户查询接口 → 看板与提醒。

每条记录至少保存：来源 URL、外部 ID、事件发生时间、来源发布时间、采集时间、时区、许可信息、修订版本和状态。所有时间以 UTC 保存，界面再转换。

## 宏观数据

- 优先官方发布机构：BLS、BEA、美联储、美国劳工部。
- 官方公布值与市场一致预期分开获取。预期值通常来自不同供应商，不能将官方历史数据误作市场预期。
- 记录前值修正与首次公布值。展示数据差异时必须确认单位、季调口径、环比/同比与报告期。
- 发布日历与报告内容独立更新。过期数据和连接错误要显式显示，不让旧缓存冒充实时数据。
- 利率决议、选举、战争等用事件对象记录；将事实、第三方观点、团队观点、AI 归纳分开，保留原文证据。

## 财报与基本面

- 公司数据以官方投资者关系页面、SEC filing/XBRL 为依据，并保存 accession number、报告期、财年和单位。
- 对同名财务指标进行口径映射，处理财报重述、累计现金流与单季现金流区别。
- 环比、同比和利润率由确定性代码计算；AI 用于有出处的解释。分母为零、负利润与缺失数据要单独处理。
- 成长预期分开显示管理层指引、外部一致预期、团队情景与模型解释；不可混合成一个无出处的数字。
- 加密资产使用独立研究模型：协议机制、发行/销毁、流通与锁仓、网络活动、手续费、持币集中度、生态和安全事件。

## X 情绪采集与分类

上线前需要确定监测账号、关键词、语言、资产和回溯窗口，并选择获授权的 API 或供应商。

建议第一批流程：

1. 保存授权来源与可追溯的 post ID，按协议处理删除与保留期限。
2. 做去重、引用/转帖区分、语言检测、资产实体识别。
3. 分类为看多/中性/看空，同时标记反讽、条件句、混合观点与模型不确定性。
4. 用人工标注样本测量分类表现与误差，保留模型版本；单独评估机器人、话题选择和账号集中造成的偏差。
5. 看板显示样本量、窗口、覆盖语言、分类占比、缺失与来源。情绪分数必须公布公式和权重，不能包装成收益保证。

当前原型使用的 68 分和 58%/27%/15% 均为模拟展示值，没有运行已训练或已验证的情绪模型。

## 每日简报与期权（2026-11-10 本地实现）

每日简报默认悉尼时间 08:00 自动生成并持久化，采用现有 RSS 和 OpenAI，支持历史阅读与同日去重。期权研究接入 Nasdaq 公开延迟链与预计财报日历，提供分布、BSM IV / Greeks、CRR 比较、跨式成本及条件异动筛选；策略页已连接真实合约、买卖报价、费用、四组合盈亏及 Greeks 比较与 AI，并保留十一种教学模板。真实链不等于 OPRA 实时行情，财报日历不等于公司确认日期，筛选不等于机构订单流，真实报价上的组合计算不等于已成交记录；教学标签仍为假设示例。见 [方法与运行说明](daily-brief-options.md)。

## 后续全平台数据实体与查询接口（规划）

| 实体                 | 关键字段                                                                | 计划接口                                       |
| -------------------- | ----------------------------------------------------------------------- | ---------------------------------------------- |
| Asset                | symbol、assetClass、exchange、currency                                  | `GET /api/assets?query=`                       |
| Quote                | assetId、price、change、asOf、source、isDelayed                         | `GET /api/markets/overview`                    |
| MacroEvent           | scheduledAt、actual、consensus、previous、revisedPrevious、unit、source | `GET /api/events`                              |
| Analysis             | sourceIds、facts、interpretation、scenarios、uncertainties、version     | `GET /api/analyses/:id`                        |
| FinancialPeriod      | filingId、periodStart、periodEnd、currency、scale、metrics              | `GET /api/assets/:id/financials`               |
| SentimentWindow      | assetId、window、sampleCount、coverage、distribution、modelVersion      | `GET /api/sentiment`                           |
| Watchlist / Reminder | userId、assetId/eventId、deliveryChannel                                | `POST /api/watchlist` / `POST /api/reminders`  |
| Course / Article     | authorId、status、version、lessons、accessTier                          | `GET /api/courses` / `POST /api/admin/content` |
| User / Subscription  | role、partnerId、tier、status、expiresAt                                | 服务端认证与订阅中间件                         |

所有供应商与模型密钥只能放在后端，不能放入 Vite 暴露的环境变量或浏览器请求。内容接口需要用户权限与订阅校验。

## 实施顺序与验收

1. **财报与估值核心（本地已实现）**：可映射发行人的官方数据、季度还原、来源核验、财务指标、参数化 FCFF、敏感性与证据导出。
2. **研究分析（AI 解读与追问已接入）**：完成 OpenAI 证据引用、上下文绑定、数值校验；后续补市场一致预期、指引、行业与竞争分析，扩大公司覆盖。
3. **宏观事件与热点（本地已接入）**：免费官方宏观来源、五个新闻 RSS、Reddit 社区榜及来源引用 AI；生产使用前确认供应商对外展示范围，并补部署、监控与编辑工作流。
4. **账号与后台基础（本地已实现）**：邮箱登录、手动授权、到期与撤销、隔离、额度及审计；生产邮件、账户清理和内容后台待完成。
5. **情绪试点**：小范围账号/主题、人工标注与分类评估，验证后再扩展。
6. **订阅、推送与运营**：测试支付代码已实现，先补真实沙盒联调；推送、内容审核、监控、备份恢复和成本保护仍需完成。

当前已使用 SEC、Twelve Data、官方宏观来源、公开 RSS、Nasdaq 及 OpenAI；X 和 TE 适配未完成真实账户验证。会员试定价见 [ToC P0](toc-launch-p0.md)，并未正式售卖。PostgreSQL / 私有 S3 已迁移、公开内测站点已运行，数据已复核，仍需发布财报兼容修复并完成备份恢复演练；商业许可和渠道资格仍须核实。
