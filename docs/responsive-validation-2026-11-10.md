# 页面自适应与滚动检查

日期：2026-11-10（Australia/Sydney）

## 本次修复

- 全局弹窗、财报指标详情使用 React portal 挂载到 document.body，避免页面动画的 transform 改变固定定位参照。
- 弹窗高度使用动态视口高度减去外边距；手机端计入安全区域，移除搜索弹窗额外的视口顶部间距。
- 弹窗保留内部纵向滚动，关闭按钮在滚动时保持可见；搜索弹窗增加可点击的关闭按钮。
- 侧边栏子项不再因短屏压缩，保留底部留白与独立滚动；字段说明浮层增加视口高度上限和内部滚动。
