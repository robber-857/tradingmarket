# 动态股票搜索与研究

## 使用路径

研究页输入股票代码或英文公司名 → 选择 SEC 官方目录候选（可用上下键与 Enter）→ 按 CIK 获取财报 → 自动获取该证券行情和历史 Beta → 查看适用的基本面指标 → AI 解读、引用及连续追问。

支持小写、前缀 `$`、`BRK.B` / `BRK-B` 别名。页面保留快捷入口和最近研究记录；全局搜索也查官方目录。新增代码可加入关注清单并跳回研究页，不给关注清单填造行情价格。

无需新增 API Key。继续使用 `.env` 的 `SEC_USER_AGENT`、`TWELVE_DATA_API_KEY` 和 `OPENAI_API_KEY`。

## 发现与核验

来源为 [SEC 官方目录说明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data) 中的 `https://www.sec.gov/files/company_tickers_exchange.json`。代码目录包含 CIK、发行人名称、证券代码和交易所。目录条目数不是支持完整估值的公司数。

- 后端磁盘缓存 24 小时；同进程 60 秒内复用解析结果。上游失败时最多使用七天内的缓存，并标记 stale；更老缓存拒绝使用。
- 研究范围为目录中 Nasdaq、NYSE、CBOE、TXSE 上市证券。OTC、未确认交易所和未找到代码返回具体原因。
- 提交前校验代码语法，只允许字母、数字及受限点号/连字符；不接受任意 URL、路径或自定义请求目标。
- 按目录 CIK 下载 Company Facts 和 Submissions，核对响应 CIK 与现有 ticker。代码重用时，不能使用前一家公司的缓存。
- 元数据与报告快照保留目录来源、采集时间、哈希、CIK、行业 SIC 和申报中关联证券。

## 数据与模型边界

财报解析目前采用 USD、US GAAP、10-Q/10-K 标准合并标签；不把 20-F/6-K、IFRS、基金申报或自定义标签硬套成美国季度财报。现有申报库只读取 SEC recent 区段，不是完整历史申报归档。最新正式报告不能解析时，显示当前可解析报告和最新申报期之间的差异。

通用 FCFF/DCF 不适用于 SIC 6000–6999 的金融类发行人。对于有多个上市证券的发行人，保守暂停公司总股权到所选证券每股口径的 DCF 与自动市值倍数；此检测可能包含优先股或其他证券，需后续逐类核验，不能声称已完成通用多股类估值。

已能还原财报的公司仍提供可得数据、真实报价、Beta 和 AI 解读。DCF 缺少必要债务、股数或连续 TTM 时显示缺口；基本面 AI 可以在 `assumptions=null` 模式下解释已有财报和行情，禁止生成 DCF 价格或不存在的估值指标。并非所有目录证券都能完整分析。

本次真实样本：AMD、AMZN 的财报、行情、倍数和 DCF 链路可用；TSLA 财报与行情可用，但标准债务映射不完整，因此不自动补齐 DCF；META、GOOGL 关联多个证券，暂停自动市值倍数/每股 DCF。TSM、SPY 和本次 JPM 标准映射不适用，显示具体原因。

## 验证

126 项离线/缓存测试通过，覆盖代码归一化、目录搜索、陈旧缓存、代码重用 CIK 隔离、动态新发行人接入、特殊申报保护和缺少 DCF 时的 AI 上下文。生产构建通过。

本次真实访问确认 AMD、TSLA、AMZN、META、GOOGL 财报；AMD、TSLA、AMZN、GOOGL 行情与 Beta。AMD 财报解读和连续追问成功，TSLA 无 DCF 的基本面解读成功，AMD 浏览器基本面解读成功。上述验证仅代表这些样本，未逐一验证目录全部证券。
