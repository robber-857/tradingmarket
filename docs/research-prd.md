# 深度研究 PRD：财报分析与基本面分析

状态：本地研究版本，更新于 2026-11-10。全平台范围和优先级见 [总 PRD](master-prd.md)。面向希望快速读懂公司、并能检查依据的个人研究者。两项功能保持独立导航。

## 核心体验

输入股票 → 选择正式财报期 → 先看三个重点 → 点击数据追溯 → 调整估值假设 → 查看情景和计算过程 → 导出证据。短结论优先，公式、原始披露和限制逐层展开。

通过 SEC 官方代码目录动态识别发行人，支持代码/英文公司名、大小写与点号别名；原四家公司保留中文别名。选择后按 CIK 拉取数据并判断申报、行业及股数口径，未适配证券给出具体原因。BTC/ETH 不进入企业财报与 FCFF，留待独立加密研究模型。

## 财报分析页面

| 区域         | 数据和操作                                                                 | 用户获得的答案                     |
| ------------ | -------------------------------------------------------------------------- | ---------------------------------- |
| 公司与报告期 | 公司名、10-Q/10-K、提交日、报告期末、原始披露链接、近八季切换、刷新        | 这是谁、哪一期、何时公布的正式业绩 |
| 三个重点     | 营收同比/毛利率变动；TTM 现金支出覆盖与现金利润比；资本开支/负债或股数变化 | 增长、现金、代价分别如何           |
| 核心数字     | 收入与同比环比、营业利润率、单季现金流减资本支出、股数同比                 | 从哪些数字得到重点结论             |
| 季度趋势     | 营收或现金流柱状图，可点选报告期                                           | 是单季异常还是持续变化             |
| 利润与增长   | 营收、毛利、利润率、营业/净利润、净利润同比环比、EPS、稀释股数             | 收入增长有没有落实到盈利           |
| 现金流质量   | CFO、资本支出、现金流减资本支出、现金利润比、SBC、投入强度；TTM 摘要       | 利润是否伴随现金，投入是否可持续   |
| 资产负债     | 资产、负债、权益、现金、映射债务、净债务、流动比率、流通股数               | 资金结构和偿债约束                 |
| 指标弹层     | 公式、原始数值、XBRL 标签、单位、报告期、申报日、accession、原文链接       | 数字是否可核验                     |
| 方法与导出   | 口径限制、缓存时间、快照 JSON                                              | 可保存、复算和持续跟踪             |

空值必须说明缺哪项输入。亏损基期不显示误导性利润增长百分比；年报还原的 Q4 不差分 EPS。正式数据未载入时提供错误和重试，不替换成演示数字。

## 基本面分析页面

| 区域         | 数据和操作                                             | 计算约束                               |
| ------------ | ------------------------------------------------------ | -------------------------------------- |
| 历史基线     | TTM 收入、营业利润率、简化 ROIC、ROIC−WACC             | 绑定选定报告期和快照                   |
| 四项主假设   | 五年增长、第五年利润率、WACC、永续增长；滑块和数字输入 | 初值标为试算假设，不能冒充公司指引     |
| WACC 解释器  | Rf、Beta、ERP、债务成本、E/D 市值，计算后明确点击应用  | 权重按市场价值；修改输入立即废弃旧结果 |
| 再投资与税率 | 常态税率、销售资本比、稳定期 ROIC                      | 正增长必须有再投资支持                 |
| 企业到股权   | 非经营现金/资产、债务、其他索偿、估值股数              | 账面债务和股数可复核后覆盖             |
| 价格对照     | 自动行情价格、条件安全边际                             | 行情来源为 Twelve Data；价格不作为现金流预测输入   |
| 三种情景     | 悲观、基准、乐观的每股条件估值及输入                   | 无发生概率；不承诺排序                 |
| 敏感性矩阵   | WACC × g 的 25 种组合                                  | 违反终值约束显示空值                   |
| 计算账本     | 每年收入、利润率、NOPAT、再投资、FCFF、现值；终值权重  | 亏损不凭空产生税收返还                 |
| 导出         | 完整财报证据、模型版本、假设、结果、计算时间           | 保存可复算研究对象                     |

输入变更后重新计算，旧结果先隐藏，避免显示旧参数结果；快速修改或切换公司时取消过期请求。公式详见 [financial-methodology.md](financial-methodology.md)。

## 服务与存储（已实现）

当前前端使用 React/Vite 与 JavaScript，Python/FastAPI 负责数据与确定性计算。本地已验证基线为文件缓存、不可变 JSON 快照及 SQLite 简报 / 账户账本；已实现邮箱登录、用户隔离、研究归档和独立普通 / 深度额度。PostgreSQL、对象存储及共享会话迁移正在另一聊天实施，未获得云端验收结论；本次仅提交文档，不包含迁移代码。

| 接口                                      | 行为                                                      |
| ----------------------------------------- | --------------------------------------------------------- |
| `GET /api/health`                         | 引擎版本、精选股票、动态目录及 LLM 配置状态                        |
| `GET /api/research/assets`                | 允许查询的公司与 CIK                                      |
| `GET /api/research/{symbol}?refresh=true` | SEC 数据、指标、证据和快照 ID                             |
| `POST /api/research/{symbol}/valuation`   | 接受 snapshot_id、report_end、assumptions；返回确定性 DCF |
| `POST /api/research-tools/wacc`           | CAPM/WACC 计算                                            |

SEC 请求在后端完成；1 小时缓存，手动刷新按 1 分钟合并，顺序请求并节流。获取失败可以返回带“更新失败”标识的历史缓存；无缓存时返回错误。联系邮箱不下发浏览器。账号隔离与服务端配额已在本地实现；生产环境仍需完成真实登录投递、持久化迁移、共享限流、调度与恢复验收。

## AI 解读与追问（已接入）

置顶三项财报摘要保留确定性规则。独立 AI 区域已接入 OpenAI Responses，用户点击后生成简洁解读并可连续追问；详见 [AI 实施说明](ai-research.md)。

AI 区域提供普通 / 深度选择，每次追问使用当前模式。两种模式共用 `OPENAI_MODEL`（默认 `gpt-5.4-mini`），深度将推理预算提高到 high、输出预算提高至 10000 tokens，并增加反例 / 敏感性 / 证伪检查；没有增加外部搜索或更换模型。服务端成功后只扣对应的一类额度，失败释放预留；财报和估值结果可保存到账户归档，但归档阅读不等于恢复原 AI 会话和全部参数。

当前服务从指定快照构建证据账本，重新计算估值、WACC 和导入样本 Beta，输出按数据事实、AI 推论和条件假设区分。模型不自行选择任意网络来源。未来可增加 `fetch_filing_section` 与 `compare_consensus` 工具，目前不声称具备附注和预期查询能力。

追问输出限制为“核心回答 + 2–3 条证据 + 条件或缺口”。来源缺失则说明无法确认。数字引用应与快照校验，不能由模型自行重新口算；严禁把指引当实际、历史价当现价。

OpenAI Key 放根目录 `.env` 的 `OPENAI_API_KEY`；保存后检查配置即可使用。SEC 获取和数学计算不需要该 Key；AI 调用仅由用户点击触发，不自动生成。模型配置为 `OPENAI_MODEL`。

## 尚未实现

完整公司行动跟踪与历史时点库；市场一致预期及其历史版本；管理层指引与电话会全文；分部、自定义 XBRL、利润一次性调整；反向 DCF、完整行业竞争分析、同业倍数和社群报告分享。缺少这些数据时不宣称“超预期”“低估”或“财报导致暴跌”。P/E/P/B/P/S 已接自动行情，Beta 已接股票与 SPY 拆股复权日线回归，也保留手动价格与导入工具；详见 [UI 与跳转逻辑](research-ui-flow.md)。

宏观官方数据、每日简报、期权分析与真实合约策略比较已经本地实现，详见总 PRD。账户会员、测试支付及手动授权已有本地实现；真实沙盒联调和部署未完成。独立 Crypto 研究、经过验证的 X 情绪模型和正式课程发布仍待开发。宏观和期权免费来源不等于实时数据流，本地实现不等于已上线服务。

## 验收要求

1. 新增公司的报告期与 SEC 申报一致，每个可得数字能追溯。
2. 单季累计差分、Q4、TTM、修订、缺失、零/负分母与债务去重均有测试。
3. 四个连续季度与年度收入核对，资产 = 负债 + 总权益；这不替代逐项人工审计。
4. DCF 与独立算例一致，终值再投资、EV 到股权桥、WACC 市值权重均有测试。
5. 非法参数、快照/公司不匹配、未知快照、非正股权价值被阻止或明确标示。
6. 浏览器核验公司/期间切换、指标出处、参数重算、输入焦点、WACC 应用、JSON 导出、移动端布局与数据失败状态。
