## 计量规则

- 普通 AI：每次成功生成/追问扣普通额度一次。
- 深度：每次成功高推理预算分析只扣深度额度一次，不同时扣普通额度。当前真实区别是 reasoning high、输出预算 10000 vs 6000，加入反例/假设敏感性/证伪检查要求；仍基于同一证据快照，不伪称多源自主深度检索。财报/估值、新闻、宏观事件及期权 AI 界面已统一提供普通 / 深度选择器。
- 免费额度按 UTC 自然月，付费按权益有效周期；额度不滚存。七天包有独立额度，不直接发一个月额度。
- 公共简报只生成一次供阅读，不对每次阅读扣次；计算器和历史阅读不扣 AI 次数。
- 机构短摘录翻译为共享缓存成本，public 模式要求登录并限制频率，不按查看重复扣个人额度。
- 市场情绪必须采用独立 bucket；目前 `reserve(..., sentiment)` 明确返回未开放，不扣次数。供应商若按文章/查询/批次计费，最终额度须按实测成本调整，不能承诺无限刷新。
- 用量预留与结果缓存保存在 SQLite。中断 pending 需要人工/后续工具核对，不默认为失败并允许无限重试。
- 相同 Idempotency-Key 和相同请求返回已完成结果；同 key 不同请求拒绝。未携带 key 的新请求视作新分析。客户端恢复重试的 key 管理仍需完善。
- 成本核算必须包含普通/深度 token、情绪供应商、支付手续费、数据许可与支持成本。当前没有足够实测账单，不能保证以上额度的毛利率。

## 澳洲支付路线与外部资料

- Stripe：澳币/美元银行卡、符合条件的 Apple Pay。支付宝为人民币单次七天或一个月购买，到期手动续购。
- PayPal：澳洲主体独立商户集成；Stripe 托管 PayPal 官方列出的商户国家主要在欧洲，不能假设澳洲 Stripe 开箱即用。
- Square：用户允许 Square 或 Stripe，本轮选 Stripe，暂不增加第二套卡收单。
- 付款币种、扣款方式、商户银行结算币种分开配置，不能承诺三种原币都能提现。
- 外部待配置：正式域名/托管、SMTP、Stripe 测试及正式账户、支付宝通道批准、PayPal 商户/API、市场情绪供应商与商业授权。密钥只在服务端环境配置，不进聊天、不进 Git。
