# Meridian 观澜 · 总产品需求文档

版本：1.0 / 2026-11-10。本文是全平台功能范围、实施状态、页面跳转和优先级的统一入口。各模块文档补充公式、接口和数据口径；与本文冲突的旧状态以本文及当前代码为准。

本轮范围：统一文档，并在现有市场总览布局上完成 Homepage 数据汇总和跳转。暂不增加其他业务模块、不部署公网、不改变订阅或数据供应商配置。Homepage 状态：已实现并完成本地验收；见 [Homepage 验收记录](validation-2026-11-10-homepage.md)。

## 1. 定位与用户

AI 驱动的美股与加密资产研究、投资学习及投资者社群平台。当前产品阶段是本地研究 MVP；目标商业形态是邀请开通的个人订阅 SaaS。不是自动交易、资金托管或收益承诺产品。

目标用户：

1. 没有时间每天阅读海外新闻和经济报告，希望迅速知道该关注什么的个人投资者。
2. 希望理解财报、估值和交易风险，并能检查公式、数据和出处的学习者。
3. 将来通过研究报告、课程和讨论服务客户的研究员与创作者。

核心任务：今天关注什么 → 事件为什么重要 → 哪些资产值得进一步研究 → 当前判断依赖什么条件 → 如何持续学习。

第一版首先建立可信的每日研究入口。美股与 Crypto 使用统一宏观框架，但股票财报模型不能直接套用于代币。

## 2. 状态定义

| 标记 | 含义 |
| --- | --- |
| 已实现 · 本地 | 有实际页面、后端或确定性计算，能在本机使用；不等于已部署或完成商业授权 |
| 部分实现 | 一部分可用，关键覆盖、数据或流程仍缺失，必须列明缺口 |
| 演示 | 模拟数值、虚构内容或仅浏览器本地操作；不能表示真实市场或多用户服务 |
| 待开发 | 尚无完成的业务闭环，不因已有导航或文案而算完成 |

数据源配置、账户权限和当次请求成功是不同状态。已写适配器但未经真实账户验证，不能标为真实数据已上线。

## 4. 数学、数据与 AI 共用规则

### 4.1 已有数学能力

| 能力 | 实现口径 |
| --- | --- |
| P/E、P/B、P/S | Twelve Data 有时点报价 × 拆股修正的最新已披露股数 / SEC 分母；市值是估算 |
| Beta | 股票对 SPY 的拆股复权日简单收益率 OLS；显示样本、区间与 R²，不含分红再投资 |
| CAPM / WACC | 股权成本、市场价值权重、税后债务成本；Beta 可带入，其余资本成本假设需核实 |
| FCFF / DCF | 五年 NOPAT 减再投资；增长受再投资约束；企业价值到股权价值桥接 |
| 永续增长 / 终值 | 稳定期再投资与 ROIC 联动，WACC 必须大于永续增长率 |
| ROIC | TTM 营业利润和假设税率 / 平均账面投入资本，未完整调整研发、商誉及租赁 |
| 情景与敏感性 | 悲观/基准/乐观条件估值、WACC × g 矩阵；不赋予未经验证的概率 |
| 期权 | BSM 反推 IV、Greeks、CRR 比较；分段线性到期盈亏、最大风险及组合 Greeks |

这些是已有模型和明确的简化口径，不称为某位经济学家对具体资产的认可。公式、参数、单位和版本可追溯。

### 4.2 数据源

SEC：财报；Twelve Data：股票报价和历史；BLS/BEA/Fed/DOL：宏观；公开 RSS：新闻；Reddit：社区摘要；Nasdaq：延迟期权与预计财报时间；OpenAI：解释与追问。X 和 TE 为可选但未完成真实验证的适配。

优先已有免费来源，数据覆盖不足明确留空。不把采集时间当报价时间，不把最新修订值当首发值，不把预计财报日期当公司正式确认。商业再分发范围在生产准备阶段核实。

### 4.3 AI

确定性代码负责数字，模型负责解释。每份输出绑定来源和快照，区分来源事实、推论、假设。具体数字以服务器登记值替换，占位符和引用必须有效；无依据的“超预期”、价格因果、胜率和保证收益不输出。

资产、报告期、事件、报价或模型参数变化时，旧上下文清空或冻结后明确提示。AI 数字格式通过校验不表示全部定性推论已被证明。

研究页生成由用户点击触发；每日简报是现有定时任务的例外。Homepage 只读取已生成内容，不因打开或刷新首页重复调用 OpenAI。

## 5. Homepage 详细需求

### 5.1 用户每日任务与布局

保留现有侧栏、页头、市场主题筛选、顶部摘要（同时显示下一项宏观事件）、横向概况条和双栏结构；复用当前 Lightness/Darkness 配色与移动布局，不重新制作营销落地页。

| 顺序 / 区域 | 内容 | 主要操作 |
| --- | --- | --- |
| 顶部 | 当前查看日期/时区、刷新、新闻主题筛选 | 刷新现有接口；筛选只影响新闻区 |
| 核心摘要 | 今日已保存简报的核心结论、生成日期、原文出处；无今日版时显示历史版日期或未生成状态 | 阅读对应日期简报 |
| 概况条 | 最近一天新闻条数、未来七天已核验排期数、简报日期、关注数量 | 跳对应模块；不冒充价格或市场方向分数 |
| 今日研究重点 | 简报最多三条关键洞察、下一步验证与风险、来源 | 阅读完整简报或来源原文 |
| 宏观关注清单 | 即将到来的最多三个事件组；状态、时间、前值/预期/实际与来源 | 打开所选事件详情；无排期明确说明覆盖不足 |
| 最新热点 | 最近二十四小时可用新闻，按选定主题和时间展示，优先覆盖不同主题 | 打开具体新闻 AI 详情 / 原文 |
| 继续研究 | 浏览器已关注股票的财报/基本面/期权入口；币种进入 Crypto 新闻 | 进入对应资产；无关注时给管理入口 |
| 来源状态 | 各区独立加载、失败、缓存和更新时间；范围说明 | 重试 / 查看对应模块 |

首页不展示原模拟指数涨跌、模拟价格曲线、固定情绪分数、虚构观点占比或演示新闻。未接入的行情总览不以装饰图替代。

### 5.2 选择与时间规则

- 简报日期固定按悉尼划分。以当前悉尼日期核对简报所属日期判断是否今日，历史版必须显示“最近一期”，不能标成今日判断。页面日期/事件时间遵循偏好；若不是悉尼需同时说明简报分日规则。
- 今日版生成中、失败或未生成时，允许展示最近已完成版并标记历史日期。没有可用版时显示明确空状态，引导简报页；不自动花费 API 额度补生成。
- 新闻按发布时间筛选过去二十四小时；来源更新失败仍保留内容时标记缓存。不可伪称 AI 选出的重要性排名。
- 宏观排期按来源真实时间排序，同类同一发布时间的总量/核心指标合并为一个入口，详情页保留完整指标。日期精度不足时只显示美东日期，不制造倒计时。
- 已过发布时间且未取得数据显示“等待核验”；不能依赖旧 status 字段继续显示即将公布。
- 缺一致预期显示“暂无预期”；无事件不能表述为“今天没有风险”。
- 各数据区独立失败，任何源失败不能让整个首页变为空白。刷新期间可保留已有内容并显示旧结果状态；过期请求不能覆盖最新响应。
- 首次进入读取三个现有来源；页面可见时每分钟检查，隐藏或卸载时停止/取消；遵守后端缓存。首页不批量请求关注股票行情，避免免费额度放大。

### 5.3 Homepage 验收

1. 首屏可看到简报结论或明确空状态，以及简报日期；无模拟市场结论。
2. 来源和时间可追溯，历史简报不会标成今日。
3. 新闻详情、事件详情、指定日期简报、股票研究跳转准确保留上下文。
4. 无数据、单源失败、全部失败、缓存、日期精度不足和过期事件有明确呈现。
5. 刷新/快速切换不会混用旧请求；浏览首页不调用 AI 生成接口。
6. 桌面和手机无页面横向溢出；原主题保留，键盘可操作，减少动态效果偏好生效。

## 6. 页面跳转与上下文

```text
市场总览
 ├─ 简报摘要 / 研究重点 → 每日市场简报（指定版日期）→ 原始来源
 ├─ 宏观关注事件 → 宏观与事件（选中该事件）→ 数据 / 来源 → AI 追问
 ├─ 新闻条目 → 市场热点（选中该新闻及来源快照）→ AI 解读 → 原文
 ├─ 关注股票 → 财报 / 基本面（同股票）→ 来源 / 估值 → AI 追问
 ├─ 关注股票的期权入口 → 期权分析（同股票）→ 策略（同到期日）
 └─ 关注币种 → 加密货币新闻（不得误入企业财报）

财报分析 ↔ 基本面分析：保留股票；报告期按股票记忆
基本面：经营质量 → 行情 / Beta → 相对估值 → DCF → AI → 指标说明
期权分析 ↔ 期权策略：保留股票、到期日、利率和股息假设
交易学院 → 课程阅读 → 本地完成记录（正式发布与社群后续实现）
```

当前使用 hash 页级路由；详情上下文由应用状态传递，直接刷新详情路由不会永久保存选中条目。要持久分享需后续增加研究对象 URL 和权限校验。浏览器返回到首页重新读取当前数据，不显示旧模拟看板。

## 8. 技术与持久化现状

前端 React 19 + Vite + JavaScript；后端 Python/FastAPI。Next.js、TypeScript、PostgreSQL 是早期技术建议，不是现有实现。当前不因编写 PRD 就承诺迁移。

财报/行情/宏观/新闻/期权使用后端缓存和 JSON 证据快照；每日简报用 SQLite。关注、课程、完成状态、偏好保存在浏览器 localStorage。AI 会话有时效且当前主要在内存中，不是长期个人研究空间。

本地服务绑定 127.0.0.1；没有生产账号鉴权、租户隔离或正式 SaaS 运维。密钥仅后端读取，不进入浏览器和导出数据。

## 9. 全局质量与验收标准

- 正确性：数据时点、口径、单位、缺失与修订清晰；确定性计算有独立算例。
- 可解释性：结论能回到来源/公式/假设；不把模型置信度、观点比例或跨式成本当上涨概率。
- 体验：首次加载/失败/重试/无数据清晰，手机可阅读，主题和键盘可用。
- 成本：AI 生成与普通读取分离；简报同日去重；行情遵守缓存和限流。
- 发布：本地测试、实际数据验证、浏览器验收、部署、客户业务验收分别记录，不互相替代。
