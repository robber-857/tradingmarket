# 真实期权链与策略比较

入口：`/#strategies` →「真实合约与策略比较」。原有独立的教学策略模板仍保留。

## 页面流程

股票代码或英文公司名称 → Nasdaq 可用到期日 → 真实合约 → 编辑买卖方向、份数及持股 → 自动比较 → AI 解读及追问。

首次选择约一个月后的可用到期日。从期权分析进入时传递股票、到期日、利率及股息假设，返回分布页同样保留这些条件。重新加载股票或到期日会重置组合，避免不同链混用。报价口径、费用及合约修改后立即隐藏旧结果和旧 AI，会话绑定重新计算的快照。

十一种模板覆盖买入看涨/看跌、备兑、保护性看跌、四种垂直价差、跨式、铁鹰、领口。模板只按最近行权价与相邻档位搭建，不是最佳合约推荐。可编辑实际合约类型、行权价、方向和每腿一至十份；每组合最多四腿，股票持仓为零或一百股。同时比较最多四个组合，仅支持同一股票和同一到期日。模板名称不随编辑后的结构重新分类，分析必须以实际腿为准。

## 报价与计算

- 数据沿用无需新增 API Key 的 [Nasdaq 公开期权链](https://www.nasdaq.com/market-activity/stocks/aapl/option-chain)。它是延迟公开数据，逐合约报价时间缺失；采集时间不等于报价时间。不保证所有股票均可用。
- 默认买入 Ask、卖出 Bid；可切换有效中间价参考，均不保证成交。不把 Last 当作成交价，双边报价缺失或倒挂时拒绝比较。
- 股票成本以来源标的价格假设新建仓，不是用户原有持股成本。每份每腿开仓费可调整，默认零；未包含平仓费、融资、股息和指派成本。
- 客户端只发送快照 ID、合约 ID 和份数等参数。报价和 Greeks 全部由后端从原始快照取值；禁止客户端传入价格覆盖真实链。
- 链计算超过十五分钟或来源采集超过三十分钟时拒绝新比较，要求刷新。供应商可能使用缓存；刷新不会保证获得新的交易所时点。
- 只适用于标准一百股合约。公开源访问稳定性、数据覆盖和对外展示权限仍需在商业上线前确认。

到期盈亏：

`Π(S) = shares × (S − S0) + 100 × Σ quantity × [intrinsic(S,K) − entryPrice] − openingFees`

`openingFees = feePerContract × Σ |quantity|`。

最大收益、最大损失由股价零点、全部行权价拐点及无穷远右尾斜率确定。盈亏平衡以分段线性求根。图表默认放大行权区间，可展开至零股价；最大盈亏独立于绘图范围，不会把绘图区间边界当作最大风险。

组合 Greeks：

`Delta = shares + 100 × Σ quantity × deltaPerShare`；其余 Greeks 为 `100 × Σ quantity × greekPerShare`。

| 指标 | 组合单位 |
| --- | --- |
| Delta | 股等效，含股票持仓 |
| Gamma | 股等效 / 标的价格美元 |
| Theta | 美元 / 自然日 |
| Vega | 美元 / 隐含波动率百分点 |
| Rho | 美元 / 利率百分点 |

Greeks 复用同一链快照有效中间价反推 IV 的 BSM 欧式近似，未建模离散股息及实际提前指派。切换建仓价不改变同一快照的模型 Greeks。任何一腿没有可靠 Greeks，整组显示缺失而非部分和；同时展示覆盖率。模型说明：[OIC Greeks](https://www.optionseducation.org/advancedconcepts/understanding-options-greeks)。

净开仓支出包括假设股票成本及费用，不是保证金需求。不提供胜率、等资金收益率排名或“最佳策略”。空头腿、宽价差、缺持仓量、无上限损失及报价下全区间无法盈利均有提示。

## AI 与接口

使用已有后端 `.env` 的 `OPENAI_API_KEY`，无需新行情 Key。OpenAI 调用仍按用量收费，点击时生成。

AI 获取当前全部比较组合、来源元数据、精确数学结果及数字引用账本。具体数值必须引用有效占位符，由服务器替换；不通过校验的回答不展示。真实报价上的假设建仓标记为「条件情景」，链接到 Nasdaq 原文。格式校验不能保证每个定性判断都正确，用户仍应结合实际合约和风险核实。

- `GET /api/options/live-templates?snapshot_id=…`：真实合约模板。
- `POST /api/options/compare`：`chain_snapshot_id`、`price_basis`、`fee_per_contract`、`scenarios`。
- 每个 scenario：`name`、`stock_shares`、`legs: [{contract_id, quantity}]`。
- `POST /api/options/explain`：沿用现有 AI 接口，支持 `live_strategy_comparison` 快照与连续追问。

本版本是本地研究功能，没有接入券商下单、跨到期策略、实盘保证金或到期前全路径估值。
